    Conseil : une playlist personnalisée (/p/nom.m3u) est plus légère, inclut films et séries, et son guide est complété pour toutes ses chaînes.

    Token de lecture

    ACCESS_TOKEN est activé : saisis-le ici pour qu'il soit ajouté aux URL copiées. Il reste dans ce navigateur.

    Mode d'emploi

    1. Crée une playlist et donne-lui un nom.
    2. Coche des catégories entières.
    3. Affine chaîne par chaîne si besoin.
    4. Enregistre, puis colle l'URL dans VLC, TiviMate ou ton lecteur Android TV.

    L'URL ne change jamais : il suffit d'actualiser la playlist dans le lecteur après une modification.
